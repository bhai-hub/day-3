## ANIMA — Haute Joaillerie
Ultra-minimal luxury web experience inspired by Bottega Veneta layered curtain architecture.

### Features
- **Layered Deck Architecture:** PowerPoint-style vertical layered transitions on scroll and swipe.
- **Bottega Veneta Layout:** Transparent floating header (`MENU` / `ANIMA` / `COMMISSION`) and centered bottom typography overlays.
- **Cinematic Media:** Full-bleed editorial physician hero, panoramic macro jewelry artifacts, and fine jewelry atelier video.
- **Quiet Luxury:** Interactive inspection dossier drawers and private anatomical commission liaison with zero commercial clutter (no prices, no buy buttons).
